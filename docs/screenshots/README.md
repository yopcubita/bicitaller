# Capturas de BiciTaller

Las capturas de esta carpeta las aportará la autora jugando en su teléfono. **No hay imágenes generadas**: todas deben ser capturas reales del juego.

## Capturas necesarias

| Archivo | Qué debe mostrar |
| --- | --- |
| `menu.png` | El menú principal al atardecer, con el título y la firma «Hecho por yopcubita» |
| `taller.png` | El taller durante una jornada: cliente a la izquierda, bici al centro y herramientas a la derecha |
| `minijuego.png` | Un minijuego en marcha (bomba, cadena o frenos), con la barra de paciencia visible |
| `cliente.png` | Un cliente con su bici y su expresión (contento, preocupado o bravo) |

## Cómo tomarlas

1. Instala el APK de prueba en el teléfono.
2. El juego es **horizontal** (1280×720): gira el teléfono y juega en apaisado.
3. Toma la captura con la función de captura de pantalla del teléfono, en cada momento de la tabla.
4. Guarda cada imagen como PNG, en horizontal, y súbela a esta carpeta con el nombre exacto de la tabla.
5. Si una captura sale con la barra de notificaciones o botones del sistema, recórtala para que solo se vea el juego.

Resolución recomendada: **1280×720** (la resolución nativa del juego).
